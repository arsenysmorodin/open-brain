# SimuBrain: Bio-Inspired Neuromorphic Simulator

## Project Goal

To develop a flexible, modular simulation platform for investigating the role of neuromodulatory systems (Dopamine, Serotonin) on adaptive behavior and learning within Spiking Neural Networks (SNNs).

## Methodology

The core of the simulation is built on biologically plausible neuron models, specifically the **Leaky Integrate-and-Fire (LIF)** model, implemented in Python.

## Current Status (Milestone 1)

Implementation and visualization of a single LIF neuron responding to constant current input.

## Getting Started

1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the main simulation: `python simulation.py`
